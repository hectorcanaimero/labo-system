## F3.3 — Package: bcv

### F3.3.T1 — Scraper BCV como Route Handler + crontab VPS

**Objetivo**

Job que scrapea `bcv.org.ve` con fetch+cheerio, parsea tasa USD, escribe en tabla. Trigger: crontab del VPS → Route Handler protegido.

**Contexto**

ARCH ADR-07 y ADR-11. S1 confirma selector y estrategia.

**Alcance**

Sí hace:
- Route Handler `POST /api/cron/scrape-bcv` protegido con header `CRON_SECRET`:
  - `fetch("https://bcv.org.ve/")` con user-agent realista (de S1).
  - `cheerio.load(html)` + selector CSS de S1.
  - Parse número (regex + Number.parseFloat).
  - Insert en `tasa_cambio_bcv` con `fuente: "bcv"`, `fecha` (hoy VE), `scraped_at` (now).
  - Retry con backoff (1 intento primario + 2 reintentos).
  - Si falla → llamar fallback DolarToday (T02).
  - Audit log de éxito/fallo.
- Línea de crontab documentada: diario 13:00 UTC (09:00 VET) llamando al endpoint con secret.

**Criterios de aceptación**

- [ ] Scrape exitoso escribe fila.
- [ ] Fetch falla → 2 reintentos backoff (1s, 3s).
- [ ] 3 fallos → invoca fallback.
- [ ] Fallo total → audit log warning, no lanza.
- [ ] Sin `CRON_SECRET` válido responde 401.

**Notas técnicas**

Alternativa documentada en ADR-11: InsForge Edge Function con Schedule (pg_cron). Se elige Route Handler para mantener un solo runtime y logs unificados.
