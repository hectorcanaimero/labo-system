# S1 · Scraper BCV sin Puppeteer

## Objetivo

Decidir cómo obtener la tasa BCV (Bs/USD) de forma automatizada, corriendo dentro de una Convex cron action (Node runtime), sin depender de Puppeteer/Chromium. La decisión gatilla la implementación de `F3.bcv` (cron + fallback + banner UI stale).

## Contexto

- PRD §10 (S1) y ARCH ADR-07 fijan el approach: `fetch + cheerio` sobre `bcv.org.ve`, con DolarToday API como fallback.
- El cron corre a 09:00 VET (13:00 UTC estándar).
- La UI muestra badge "Tasa vieja" cuando `scraped_at > 24h`.

## Alcance

Sí hace:
- Prototipar el scrape de `bcv.org.ve` con `fetch` + `cheerio` desde Node.
- Medir estabilidad del selector CSS/HTML durante al menos 3 días (mañana + tarde).
- Prototipar el fallback a DolarToday (o API tercero equivalente).
- Documentar user-agent, headers, y estrategia de reintento con backoff.
- Definir contrato de la tabla `tasa_cambio_bcv` (ya fijado en ARCH §6, sólo validar).
- Documentar cómo detectar "scrape roto" (HTML cambió) vs "sitio caído".

No hace:
- Implementar el cron final (eso es `F3.bcv.T*`).
- Implementar la UI badge (eso es `F3.bcv.T*`).
- Elegir tercero comercial pago.

## Criterios de aceptación

- [ ] Documento de decisión con: fuente primaria elegida, selector/parser exacto, fallback confirmado, TTL de retry.
- [ ] Script proof-of-concept que devuelve `{ tasa: number, scraped_at: number, fuente: "bcv"|"dolartoday" }`.
- [ ] Prueba durante 3 días consecutivos sin falso positivo.
- [ ] Lista de headers/user-agent necesarios para no ser bloqueado por Cloudflare/rate-limit.
- [ ] Definición de umbral `stale` (default: 24h).
- [ ] Alerta/log estructurado para "scrape roto" identificable en Convex logs.

## Learning outputs

- Contrato exacto del action `scrapeBCV` que consumirá `F3.bcv.T*`.
- Lista de riesgos (Cloudflare, cambio HTML, rate-limit) con mitigación.
- Fallback validado end-to-end.

## Blocked features

- F3.bcv.T01 → T0N (cron, fallback, banner UI)

## Notas técnicas

- Ejecutar el POC como script local Node (`scripts/spike-s1-bcv/`), fuera de Convex, para poder testear rápido.
- Al portar a Convex action: recordar `"use node"` directive.
- Cheerio funciona en Convex Node runtime (verificar `package.json` de convex node target).
